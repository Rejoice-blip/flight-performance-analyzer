How It's Calculated

1. Air density (ρ) — uses the International Standard Atmosphere model, which predicts how air pressure and temperature drop as altitude increases. At {{ results.altitude_m }} m, this works out to ρ = {{ results.air_density }} kg/m³ (sea level is about 1.225 kg/m³, so the air here is {{ 'thinner' if results.air_density < 1.225 else 'about the same density' }}).

2. Weight (W) — Weight = mass × gravity
W = {{ results.mass_kg }} kg × {{ results.gravity }} m/s² = {{ results.weight }} N

3. Required lift coefficient (CL) — this is how much "lifting power" the wing shape needs to produce at your chosen speed, so that lift exactly balances weight.
CL = 2W / (ρ × V² × S)
CL = 2 × {{ results.weight }} / ({{ results.air_density }} × {{ results.your_speed }}² × {{ results.wing_area_m2 }}) = {{ results.cl }}

4. Drag coefficient (CD) — every wing has some baseline drag (CD0) plus extra drag that comes from producing lift (the k × CL² term).
CD = CD0 + k × CL²
CD = {{ results.cd0 }} + {{ results.k }} × {{ results.cl }}² = {{ results.cd }}

5. Lift (L) — the upward force the wings generate at your input speed.
L = 0.5 × ρ × V² × S × CL
L = 0.5 × {{ results.air_density }} × {{ results.your_speed }}² × {{ results.wing_area_m2 }} × {{ results.cl }} = {{ results.lift }} N

6. Drag (D) — the backward force resisting the plane's motion at your input speed.
D = 0.5 × ρ × V² × S × CD
D = 0.5 × {{ results.air_density }} × {{ results.your_speed }}² × {{ results.wing_area_m2 }} × {{ results.cd }} = {{ results.drag }} N

7. Stall speed (Vstall) — the slowest speed the plane can fly before the wings stop producing enough lift (CL max reached).
Vstall = √(2W / (ρ × S × CLmax))
Vstall = √(2 × {{ results.weight }} / ({{ results.air_density }} × {{ results.wing_area_m2 }} × {{ results.cl_max }})) = {{ results.stall_speed }} m/s

8. Lift-to-drag ratio (L/D) — a measure of aerodynamic efficiency: how much lift you get per unit of drag.
L/D = Lift ÷ Drag
L/D = {{ results.lift }} ÷ {{ results.drag }} = {{ results.ld_ratio }}

9. Thrust-to-weight ratio (T/W) — compares the engine's push to the plane's weight; higher means more acceleration and climb potential.
T/W = Max thrust ÷ Weight
T/W = {{ results.max_thrust_n }} ÷ {{ results.weight }} = {{ results.twr }}

10. Excess thrust — how much "extra" push the engine has left over after overcoming drag. This spare thrust is what climbs the plane.
Excess thrust = Max thrust − Drag
Excess thrust = {{ results.max_thrust_n }} − {{ results.drag }} = {{ results.excess_thrust }} N

11. Rate of climb (ROC) — how fast (in m/s) the plane can gain altitude, using that leftover excess thrust.
ROC = (Excess thrust × V) ÷ Weight
ROC = ({{ results.excess_thrust }} × {{ results.your_speed }}) ÷ {{ results.weight }} = {{ results.roc }} m/s
